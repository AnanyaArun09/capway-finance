# CapWay - Advanced Financial & Scholarship Clearinghouse 📈

CapWay is an advanced, student-focused Financial and Scholarship Clearinghouse built to demystify college transparency, financial aid indexing, and long-term liabilities. Engineered specifically for high school families navigating the complex higher education landscape, the application allows users to dynamically track need-based aid guidelines and compare up to five unique institutional merit matrix profiles side-by-side.

##  How to Run the Application Locally

This project is built using a clean, client-side web stack architecture. It runs entirely in the browser without requiring heavy installations or backend server configurations.

1. Click the green **Code** button at the top right of this repository page.
2. Select **Download ZIP** from the dropdown menu.
3. Locate the downloaded file on your computer and **Extract/Unzip** the folder contents.
4. Open the unzipped directory and double-click **`index.html`**.
5. The application will launch instantly inside your default web browser (Chrome, Safari, Edge, or Firefox) with all interactive calculation structures and modern theme layers fully functional.

##  Tech Stack Architecture
* **Frontend Structure:** HTML5 Semantic Markup
* **Interface Styling:** CSS3 Custom Variables & Responsive Grid Layouts
* **Calculation Core:** Native JavaScript (ES6 Code Arrays & Amortization Formulas)
* **Development Environment:** Visual Studio Code & GitHub Copilot Chat
